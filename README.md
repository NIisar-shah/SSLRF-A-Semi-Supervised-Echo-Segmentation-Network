# SSLRF-A-Semi-Supervised-Echo-Segmentation-Network
This repo is about echocardiographic segmentation using a semi-supervised network
Download CAMUS and Echo-Net from their websites. https://www.creatis.insa-lyon.fr/Challenge/camus/, https://echonet.github.io/dynamic/index.html#dataset,
extract the images from EchoNet videos. The labelled-to-unlabelled ratio should be 20:80, respectively, using the Python file extract_echonet_frames.py. the full code will be published here upon article acceptance
